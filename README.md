# Help Desk Troubleshooting Lab

## Project Overview

This project documents hands-on IT support scenarios completed in the ServiceDesk Simulator. It demonstrates my practice with Tier 1 troubleshooting, account administration, networking, file access, hardware support, and professional ticket documentation.

**Environment:** ServiceDesk Simulator  
**Project status:** In progress

> **Note:** These are simulated support scenarios, not incidents from an actual workplace. Results are described based on the simulator workflow.

## Security Practices

- Verify user identity before account changes.
- Never include passwords or verification codes in reports.
- Follow approved procedures for handling temporary credentials.
- Clearly distinguish simulated practice from real workplace experience.

## Project Goals

My goal is to continue documenting all 15 scenarios, improve my troubleshooting process, and build practical skills relevant to entry-level IT support and help desk roles.
